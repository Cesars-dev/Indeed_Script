# Milestone 24 — Playwright + Gemini Vision Pivot

## Status: IN PROGRESS — code written, end-to-end test pending

---

## Why We Pivoted (nodriver → playwright)

nodriver hit a structural wall:
- `best_match=True` fuzzy-match clicked wrong elements (nav bar instead of Apply button)
- WebSocket 500 crashes mid-SmartApply session
- 15-step hardcoded state machine — every new step type broke it
- CF bypass Layer 2 (Turnstile) added complexity without fixing root cause

**New approach:** playwright (battle-tested CDP client) + Gemini Vision (AI sees the page, decides what to do). Zero hardcoded selectors.

### 4. Built `src/playwright_indeed.py`
Drop-in replacement for `nodriver_indeed.py`. Same interface:
```python
result = await apply_to_job(apply_url, docx_path, user_id)
# {"status": "success"|"failed"|"skipped"|"disqualified", "reason": "..."}
```

**Architecture:**
```
apply_to_job(url, docx_path, user_id)
  ├── _start_profile()              → AdsPower API → debug_port
  ├── playwright.connect_over_cdp() → attach to AdsPower browser
  ├── _working_tab()                → tab[0] untouched, work in tab[1]
  ├── goto(indeed.com)              → warmup 5–10s
  ├── goto(apply_url)
  ├── Find Apply button             → CSS selectors first, text fallback
  ├── apply_btn.click()
  └── _gemini_loop() — 20 steps:
        ├── hard guards (settings redirect, success, disqualified)
        ├── deterministic file upload (input[type='file'] detected)
        ├── page.screenshot() → bytes
        ├── Gemini Vision → JSON {action, target, value, reason}
        └── _execute() → click / fill / select_option / scroll / upload
```

**Gemini Vision prompt** gives the model:
- Applicant info: name, email, phone, years exp, education, salary
- Current URL + step number
- Screenshot (PNG bytes via `types.Part.from_bytes`)
- Returns single JSON action per call

**Action types Gemini can return:**
```
click, fill, select_option, scroll, upload, done, failed, skip
```

## Key Decisions

| Decision | Reason |
|---|---|
| No playwright-stealth plugin | AdsPower handles all fingerprinting — adding stealth conflicts |
| No playwright-mcp SSE server | Automated pipeline calls playwright Python directly, no interactive MCP needed |
| No custom headers/UA | AdsPower browser is already configured by AdsPower |
| Gemini Vision instead of hardcoded selectors | Handles any SmartApply layout change without code updates |
| Deterministic file upload (no Gemini) | `input[type='file']` detection is always the same DOM element |
| Hard guards before Gemini | Settings/success/disqualified detected cheaply without API call |
| `google-genai` not `google.generativeai` | Old SDK end-of-life |
| Gemini 2.0 Flash | 1000 req/day on paid plan — enough for ~50 job applications |

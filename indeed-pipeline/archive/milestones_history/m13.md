# Milestone 13 — VPS AdsPower Authentication via LocalStorage Injection

## Status: DONE ✅ — VPS AdsPower authenticated, all 10 profiles visible

## Summary

VPS AdsPower is now fully authenticated and self-contained.
Mac's LocalStorage + IndexedDB were copied to VPS — VPS AdsPower woke up already logged in.
**Mac no longer needs to be running for VPS scripts to access AdsPower.**

---

## What Was Blocked (VNC path — abandoned)

`export_cookies.py` was fundamentally broken:
- Checked `JSESSIONID` as proof of login — Indeed sets this for ALL visitors, not just logged-in users
- Silent `except: pass` blocks hid every login failure
- Result: 6 fake cookie files — visitor-level sessions, not authenticated accounts

VNC path was also blocked:
- AdsPower's Electron BrowserWindow will NOT render its UI content on Xvfb (virtual display)
- 8 GPU/GL flag combinations tried — all resulted in blank white webContents
- Root cause: Xvfb has no GPU; Electron's Chromium renderer requires GPU compositing to paint

---

## What Fixed It — LocalStorage Injection

AdsPower stores its auth token in `Local Storage` + `IndexedDB` as a standard web token (NOT Keychain-encrypted).
Copying Mac's session data to VPS made VPS AdsPower wake up already authenticated.

```bash
# On Mac:
cd ~/Library/Application\ Support/adspower_global/
tar czf /tmp/ads_session.tar.gz "Local Storage" "IndexedDB"
scp /tmp/ads_session.tar.gz root@45.55.90.156:/tmp/

# On VPS:
systemctl stop adspower
cd /root/.config/adspower_global/
tar xzf /tmp/ads_session.tar.gz
chown -R root:root "Local Storage" "IndexedDB"
systemctl start adspower
sleep 8

# Verify (port 20725 = VPS-native AdsPower):
curl "http://localhost:20725/api/v1/user/list?api_key=6690380481d7de70c40230dca72e9403005bda7f364e3e6f&page=1&page_size=10"
# Returns: {"code":0,"msg":"Success","data":{"list":[...10 profiles...]}}
```

## Critical Architecture Facts

### AdsPower port facts:
- **`--api-port` flag is IGNORED** — AdsPower always binds to port **20725** internally
- VPS-native API: `http://localhost:20725/api/v1/...?api_key=KEY` ← use this for VPS scripts
- Port 50325 on VPS = still the autossh `-R` tunnel pointing to Mac's AdsPower ← old path
- Mac tunnel path (`localhost:50325`) still works when Mac is on, but no longer required

### VPS AdsPower service:
- Headless mode (`--headless true`) — no GUI, no Xvfb required
- Service: `adspower.service` → `/opt/start-adspower.sh`
- API key: `6690380481d7de70c40230dca72e9403005bda7f364e3e6f`
- Config data: `/root/.config/adspower_global/`

### Tunnel config (unchanged):
```
-L 3001:localhost:3001   # Mac → VPS MCP servers
-L 3002:localhost:3002
-L 3003:localhost:3003

```

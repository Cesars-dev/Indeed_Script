## What Was Done This Session (M17 → M18)

### 1. DOCX → PDF conversion pipeline

**Problem:** Google Drive exports DOCX files < 100 KB. DOCX is accepted by Indeed's upload
input but PDF is parsed more reliably (no font/formatting issues, better text extraction for
employer ATS screening).

**Solution:** LibreOffice headless conversion injected between download and upload.

**`src/gdrive_client.py` — new function:**
```python
def convert_docx_to_pdf(docx_path: str) -> str:
    """Convert a DOCX file to PDF using LibreOffice headless. Returns the PDF path."""
    out_dir = os.path.dirname(os.path.abspath(docx_path))
    subprocess.run(
        ["libreoffice", "--headless", "--convert-to", "pdf", "--outdir", out_dir, docx_path],
        check=True, timeout=60, capture_output=True,
    )
    pdf_path = os.path.splitext(docx_path)[0] + ".pdf"
    if not os.path.exists(pdf_path):
        raise RuntimeError(f"PDF conversion produced no output: {pdf_path}")
    return pdf_path
```

**`src/apply_runner.py` — changes:**
- Imports `convert_docx_to_pdf`
- After DOCX download: attempts PDF conversion, falls back to DOCX on failure
- Passes `upload_path` (PDF or DOCX) to `apply_to_job` instead of `docx_path`
- Cleanup uses `{docx_path, upload_path}` set — deduplicates if same file (fallback case)

**Install LibreOffice:**
- VPS: `sudo apt install -y libreoffice`
- Mac: `brew install --cask libreoffice` (or already installed)

### 2. Dropdown (`<select>`) handler added to state machine

**Problem:** M17 listed `<select>` dropdowns as the #1 known gap. Indeed shows them for:
education level, employment type, work schedule, shift preference, and others.

**Design:** JS runs every loop iteration, before the radio/text handler. Already-filled selects
are skipped. Empty + visible selects get smart defaults.

**Rules:**
| Dropdown context keywords | Chosen option |
|---|---|
| education / degree / diploma / school | "High School" → "Bachelor's" → first |
| employment type / job type / work type | "Full" (Full-time) → first |
| everything else | first non-empty option |

**Implementation (added to `_complete_application` before the radio/text block):**
```python
# === Dropdowns — runs every step, no-op if all already filled ===
await page.evaluate("""
    (() => {
        document.querySelectorAll('select').forEach(sel => {
            if ((sel.value && sel.value !== '') || sel.offsetParent === null) return;
            const opts = Array.from(sel.options).filter(o => o.value !== '' && !o.disabled);
            if (!opts.length) return;
            const lbl = document.querySelector('label[for="' + sel.id + '"]');
            const ctx = (lbl ? lbl.textContent : (sel.closest('div,fieldset') || sel).textContent || '').toLowerCase();
            let chosen = null;
            if (['education', 'degree', 'diploma', 'school'].some(k => ctx.includes(k))) {
                chosen = opts.find(o => o.text.toLowerCase().includes('high school'))
                      || opts.find(o => o.text.toLowerCase().includes('bachelor'))
                      || opts[0];
            } else if (['employment type', 'job type', 'work type'].some(k => ctx.includes(k))) {
                chosen = opts.find(o => o.text.toLowerCase().includes('full')) || opts[0];
            } else {
                chosen = opts[0];
            }
            if (chosen) {
                const setter = Object.getOwnPropertyDescriptor(window.HTMLSelectElement.prototype, 'value').set;
                setter.call(sel, chosen.value);
                sel.dispatchEvent(new Event('change', {bubbles: true}));
            }
        });
    })()
""")
await _delay(0.3, 0.6)
```

**Same pattern as text inputs:** React-native setter + `change` event dispatch to trigger
framework reactivity.

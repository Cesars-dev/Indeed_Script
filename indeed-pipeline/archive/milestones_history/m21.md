## What Was Done This Session (M20 → M21)

### 1. Created `scripts/smartapply_inspector.py`

Passive DOM observer — attaches to an AdsPower profile and watches while the USER
navigates manually. On every URL change (and every 10s): takes screenshot + dumps
full DOM to console and JSON file. Never clicks anything.

**What it captures per step:**
- URL + page title
- Progress bar %
- All visible buttons (text + id)
- File inputs (resume upload points)
- Text inputs + labels + current values
- Select dropdowns + options + selected value
- Radio groups + which option is checked
- Checkboxes
- Key visible paragraphs / question text
- Form actions

**Output:** `/tmp/inspector_<profile>_<ts>/` — one PNG + one JSON per URL change

**Run:** `venv_local/bin/python scripts/smartapply_inspector.py`

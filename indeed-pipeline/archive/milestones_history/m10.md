---

## Root Causes

### 1. Direct URL navigation is more suspicious than typing in search box
Jumping straight to `/jobs?q=...` after homepage = bot pattern. Cloudflare scores it higher risk.

### 2. Cloudflare Turnstile is not a normal checkbox
It analyzes mouse trajectory, hover timing, pointer events *before* the click. A raw CDP `element.click()` with no prior mouse movement = instant bot signal. Do NOT attempt to click it programmatically.

### 3. Search box selector missed
`input#text-input-what` and `input[name='q']` both failed on this logged-in profile. Indeed's logged-in homepage may render different markup (React component, different IDs). Need to inspect the actual DOM in AdsPower browser to get correct selectors.

### 4. `input()` pause for CAPTCHA is wrong approach
Automation means zero fingers lifted. CAPTCHA should trigger profile rotation, not a user pause.

### Navigation pattern — homepage first, use search box, no direct URL
1. `indeed.com` → wait 8–15s → scroll 2–3 times
2. Find search box → type per-char → fill location → press Enter
3. ONLY fall back to direct URL if search box genuinely not found, and add 10s extra delay before fallback

### Mouse warmup before any click
Before clicking anything sensitive: move mouse over element area, hover 1–2s, then click.

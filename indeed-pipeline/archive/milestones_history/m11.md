## Problems Found in M10

### 1. Hardcoded profile ID
`TEST_PROFILE_ID = "k19sp7sp"` — single point of failure. One bad profile = dead run.

### 2. Session not saved in test profile
When user clicked the Turnstile manually, Indeed prompted login → profile `k19sp7sp`
had no `indeed_sess` cookie stored in AdsPower. Fresh session = high Cloudflare risk score.

### 3. `input()` pauses for CAPTCHA are unacceptable
Automation means zero fingers lifted. Any `input()` pause breaks the goal.

### 4. No page state observation before acting
Script acted blindly after navigation. Needed: read page → classify → decide.

---

## Cloudflare Turnstile — Definitive Strategy

**nodriver cannot bypass Turnstile once it appears.** It always rejects programmatic clicks
because CF scores behavior throughout the entire page visit, not just at click time.

**The only bypass is prevention:**
- Valid `indeed_sess` cookies from a real prior login → CF scores profile as returning human
- Natural navigation: homepage → search box (not direct URL) → human typing + scrolling
- AdsPower provides fingerprint spoofing + residential proxy + cookie persistence

**If Turnstile appears anyway → rotate to next profile immediately.**
Different profile = different IP + different cookie history = fresh CF score.

### Supabase profile fetch
```python
def fetch_profiles() -> list[dict]:
    r = requests.get(
        f"{SUPABASE_URL}/rest/v1/adspower_profiles",
        params={"cookie_status": "eq.success", "order": "account_slot.asc", ...},
        headers=SUPA_HEADERS,
    )
    return r.json()
```
Loads all 10 profiles (all `cookie_status: success`) from `adspower_profiles` table.
Ordered by `account_slot` so slot 1 is always tried first.

### Profile rotation loop
```python
for profile in profiles:
    result = await run_session(profile)
    if result == "success":
        break
    # else rotate: cloudflare / captcha / login_required / no_jobs / error
```
Stops current profile, waits 3s, tries next. All 10 profiles available before giving up.

### Observation checkpoints
State is checked at three points — never blind navigation:
1. After homepage load (8–15s idle)
2. After search (5–8s wait)
3. After job page load (10–22s read)

### Mouse hover before clicks
`human_click()` now waits 0.8–1.5s after `scroll_into_view()` before clicking,
simulating mouse settling on the element before the click event fires.

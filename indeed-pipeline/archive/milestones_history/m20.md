## What Was Done This Session (M19 → M20)

### 1. Root cause: wrong button was being clicked

**Old code:**
```python
for label in ["Apply now", "Easy Apply"]:
    apply_btn = await page.find(label, best_match=True, timeout=5)
```

**Problem:** `page.find("Apply now", best_match=True)` was semantically matching something in
the **global navigation bar** (not the blue "Apply with Indeed" IndeedApply widget). Evidence:
the settings redirect URL contained `from=gnav-util-viewjob` — `gnav` = global nav.

**Fix — CSS selectors first, then exact text match:**
```python
for selector in [
    "[data-testid='indeedApplyButton']",
    ".ia-IndeedApplyButton",
    "button[class*='IndeedApply']",
    "[data-indeed-apply]",
    "button.jobsearch-IndeedApplyButton-newDesign",
    "#indeedApplyButton",
]:
    apply_btn = await page.select(selector, timeout=2)
    if apply_btn: break

if not apply_btn:
    for label in ["Apply with Indeed", "Apply now", "Easy Apply"]:
        apply_btn = await page.find(label, best_match=False, timeout=5)
        if apply_btn: break
```

**Result:** Script now correctly enters SmartApply — URL changes to
`smartapply.indeed.com/beta/indeedapply/form/...`

### 2. SmartApply location step — stuck in loop

**Screenshots step_00/01/02:** All identical. Page: **"Review your location details from your
profile"** — 38% progress bar, Country: United States, Zip code: 14202 (Buffalo, NY).

**Root cause:** The Continue button (`button[type='submit']`) is **below the fold**. The state
machine was calling `page.find("Continue", best_match=True)` which fuzzy-matched **"Save and
close"** (visible at top of page). Clicking "Save and close" exits SmartApply → settings
redirect. Loop repeats 3 times before WebSocket 500 crash.

**Fix applied:**
```python
# Scroll down first — Continue is often below fold
await _human_scroll(page, steps=1)
# CSS selector first
for selector in ["button[type='submit']", ".ia-continueButton", "[data-testid='continue-button']"]:
    btn = await page.select(selector, timeout=2)
    if btn: ...
# Exact text match fallback — no best_match
for label in ["Continue", "Next"]:
    btn = await page.find(label, best_match=False, timeout=2)
```

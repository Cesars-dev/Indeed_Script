## What Was Done This Session (M22 → M23)

### Strategy: Firefox cookie extraction → AdsPower injection

**Problem:** Google blocks Gmail login from new AdsPower browser profile + proxy.
**Solution:** Log into Gmail on Firefox (real Mac IP, no proxy) → extract cookies from
Firefox's SQLite database → inject into AdsPower profile via API.

**Why Firefox:**
- Cookies stored in plain SQLite file (`cookies.sqlite`) — no extension needed
- Readable with Python's built-in `sqlite3` module
- No need for Chrome's encrypted cookie store (requires Keychain on Mac)

**Flow per account (one time only):**
1. Open Firefox → log into Gmail account → log into Indeed
2. Run `scripts/inject_firefox_cookies.py --user-id k19td4vp`
3. Script reads Firefox cookies.sqlite → formats → POSTs to AdsPower API
4. Profile now has valid Google + Indeed session — proxy re-enabled automatically

## Architecture (Hybrid)

```
9 AM cron → orchestrator.py (VPS)
  └─ Query Supabase → POST N8N webhook

N8N: Apify → qualify → proposals → Google Docs → Google Sheets
  └─ Final node: POST http://45.55.90.156:8080/apply {csv_url}

webhook_server.py (VPS, always on)
  └─ Spawns apply_runner.py
       └─ Load CSV → dedupe via Supabase
       └─ Download DOCX from Google Drive
       └─ Nodriver + cookies → Indeed apply
       └─ Log result to Supabase applied_jobs
```

Cookies: Exported from AdsPower (Mac) → uploaded to VPS once.
Sessions last weeks. Re-run export_cookies.py when they expire.

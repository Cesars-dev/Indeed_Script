## What Was Done This Session (M15 → M16)

### 1. CF Bypass — Layer 2 added (Turnstile click)

**Problem:** `_handle_cloudflare` (Layer 1) only waits for JS challenges to auto-resolve.
Interactive Turnstile challenges require a click — they never self-resolve, causing 25s timeout.

**Fix:** Added `src/nodriver_cf_verify.py` (sourced from GitHub: KlozetLabs/nodriver-cf-bypass)
and wired it as Layer 2 before the JS wait.

**Key discovery:** Research doc (`Cloudfare bypass.md`) had WRONG class/method names:
- Doc said: `from nodriver_cf_bypass import CFBypass` → `.bypass()`
- Actual:   `from nodriver_cf_verify import CFVerify` → `.verify()`
- Package not on PyPI — must be sourced directly from GitHub repo

**New function `_clear_cloudflare(page)`** — replaces bare `_handle_cloudflare` calls:
```python
async def _clear_cloudflare(page, timeout: int = 25) -> bool:
    # Layer 2: Turnstile — finds iframe, clicks it if CF challenge present
    cf = CFVerify(_browser_tab=page, _debug=False)
    await cf.verify(_max_retries=10, _interval_between_retries=2, _reload_page_after_n_retries=3)
    # Layer 1: JS challenge wait
    return await _handle_cloudflare(page, timeout=timeout)
```

Called after both `page.get()` calls (warmup + job page).

**Why same-tab beats new_tab=True for CF:**
- Same tab: referrer = `indeed.com` → job URL = natural human navigation
- New tab: no referrer → direct hit → more suspicious to CF
- Research doc's `new_tab=True` recommendation was for session preservation, not CF bypass

### 2. Tab Management — AdsPower health tab preserved

**Problem:** AdsPower default tab[0] = health/proxy/status page (e.g. netlify app).
Old `_get_tab` was closing ALL tabs except tab[0] and using tab[0] — wrong on both counts:
- tab[0] should never be touched
- All work should happen in tab[1]

**Fix:**
```python
async def _get_tab(browser) -> uc.Tab:
    """Leave tab[0] (AdsPower health page) untouched. Work in tab[1]."""
    tabs = browser.tabs
    for tab in tabs[2:]:          # close only excess tabs beyond index 1
        await tab.close()
        await asyncio.sleep(0.3)
    tabs = browser.tabs
    if len(tabs) > 1:
        return tabs[1]            # use existing tab[1]
    return await browser.get("about:blank", new_tab=True)  # or open fresh
```

### 3. Return-home on profile stop

**Problem:** After apply, profile was stopped with tab sitting on job/confirmation page.
Next run: AdsPower restored that stale URL, script overwrote it — wasted state.

**Fix:** `finally` block navigates tab[1] back to `indeed.com` before `_stop_profile`:
```python
finally:
    try:
        await page.get("https://www.indeed.com")
        await asyncio.sleep(2)
    except Exception:
        pass
    _stop_profile(user_id)
```

Now each profile is saved with indeed.com warm and ready for the next run.

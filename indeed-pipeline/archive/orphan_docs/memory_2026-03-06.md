## CF Bypass Technical Details

### What `_is_cf()` checks (in `playwright_indeed.py`)
- Title contains: "just a moment", "attention required", "security check", "additional verification", "verify you are human"
- DOM scripts include: `challenges.cloudflare.com`, `cdn-cgi/challenge-platform`, `turnstile/v0/api.js`

### What `_bypass_cf()` does
1. Checks `_is_cf()` — if clear, returns True
2. Looks for Turnstile iframe via 5 CSS selectors (but NOTE: shadow DOM hides them from `querySelectorAll`)
3. If iframe found: Bezier mouse movement → click checkbox
4. If no iframe: waits for auto-resolve (3-6s)
5. Every 3 attempts: reloads page
6. Max 8 attempts

### Key discovery: `page.frames` vs `querySelectorAll`
- `document.querySelectorAll('iframe')` returns 0 — Turnstile uses shadow DOM
- `page.frames` returns 2 frames (main + `challenges.cloudflare.com/turnstile/...`)
- To interact with Turnstile on managed challenge pages, use `page.frames` not DOM selectors
- However, for datacenter IPs this is moot — CF auto-solves but re-challenges anyway

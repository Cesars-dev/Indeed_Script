## Failure Pattern #1: SmartApply Stuck on Questions Page

### What happens
1. Page URL: `/questions-module/questions/1` (multi-question page)
2. Gemini Flash takes **viewport screenshot** (only sees top of page)
3. Fills the first visible question correctly (e.g., "Have you worked for Texas Oncology?")
4. URL doesn't change (more questions or Continue button below fold)
5. Code tries `handle_continue_button` → fails (button below viewport)
6. `same_url_actions` hits 3 → escalates to Pro
7. Pro takes **full page screenshot** but by now has burned 7+ shots
8. Pro also gets stuck because prompt doesn't say "you already filled fields above"
9. Exhausts 12 shots → fails

### Root Cause: THREE coordination gaps

**Gap A — Viewport-only screenshot on Flash**
- `_screenshot(page, ..., full_page=False)` at line 219 of `router.py`
- Flash (shots 5-8) only sees what's visible in viewport
- The Continue button and additional questions are BELOW the fold
- Pro (shots 9-12) DOES take full page, but by then we've burned 7 shots

**Gap B — No auto-scroll after fill on same URL**  
- After a successful fill, code checks `handle_continue_button` (line 277)
- But it doesn't scroll first — the button is invisible
- Line 158 scrolls 30% on deterministic retry, but not after Flash fill

**Gap C — Prompt lacks "you're stuck" context**
- `build_targeted_prompt()` in `gemini_fallback.py` doesn't know about `same_url_actions`
- Gemini doesn't know it already filled fields — may re-attempt or get confused
- No guidance to scroll down or look for Continue when stuck

### Evidence
```
  ── step 03 ── .../questions-module/questions/1   ← enters questions page
  ── step 04 ── .../questions-module/questions/1   ← still here
  ── step 05 ── .../questions-module/questions/1   ← still here
  ...
  ── step 17 ── .../questions-module/questions/1   ← 14 steps on same page!
```

All 9 stuck failures show this exact pattern. Every attempt is on `/questions/1` through `/questions/4`.

### P1: Fix Questions Page Loop (PROMPT CHANGES + CODE)

#### P1a: Auto-scroll after fill when URL unchanged
**File:** `src/smartapply/router.py` lines 267-287  
**Change:** After a successful Flash fill where URL didn't change AND we're on a `/questions` page:
1. Scroll down 400px
2. Wait 1s for page to settle
3. Re-scan DOM before next shot

```python
# CURRENT (line 267-272):
post_url = page.url
if post_url != url:
    shot = 0
    same_url_actions = 0
else:
    same_url_actions += 1
    # tries handle_continue_button...

# PROPOSED:
post_url = page.url
if post_url != url:
    shot = 0
    same_url_actions = 0
else:
    same_url_actions += 1
    # Scroll to reveal Continue button or next question
    if "questions" in url:
        await page.evaluate("window.scrollBy(0, 400)")
        await asyncio.sleep(0.8)
    # Then try Continue...
```

#### P1b: Use full-page screenshot on Flash when stuck (2+ same URL)
**File:** `src/smartapply/router.py` line 219  
**Change:** When `same_url_actions >= 2`, take full-page screenshot even on Flash tier

```python
# CURRENT:
screenshot = await _screenshot(page, debug_dir, f"step_{step:02d}")

# PROPOSED:
use_full = same_url_actions >= 2  # stuck on same page — show everything
screenshot = await _screenshot(page, debug_dir, f"step_{step:02d}", full_page=use_full)
```

#### P1c: Add stuck context to Gemini prompt  
**File:** `src/smartapply/gemini_fallback.py`, function `build_targeted_prompt()`  
**Change:** Accept `same_url_actions` param and prepend stuck guidance

```python
# CURRENT prompt starts with:
"You are filling a job application form. "
"The DOM state shows unanswered elements below. "
"Pick the SINGLE NEXT ACTION to progress.\n"

# PROPOSED — when same_url_actions >= 2:
"You are filling a job application form. "
"WARNING: You have already completed actions on this page but it has NOT advanced. "
"Fields you already filled are visible in the screenshot. "
"DO NOT re-fill already-filled fields. Instead: "
"1. Look for a 'Continue' or 'Next' button and CLICK it, OR "
"2. Scroll down to reveal more questions below the visible area, OR "
"3. Look for any UNFILLED required fields you may have missed.\n"

# When same_url_actions < 2 (normal):
"You are filling a job application form. "
"The DOM state shows unanswered elements below. "
"Pick the SINGLE NEXT ACTION to progress.\n"
```
